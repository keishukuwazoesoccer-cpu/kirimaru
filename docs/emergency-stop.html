運営者向け：緊急停止・復旧手順

本番の停止・復旧操作は管理者の承認後に実施してください。

  1. 発生時刻・対象版・影響範囲を記録し、実データを公開Issueへ載せず学校の担当者と連携します。
  2. AI送信を止める場合、承認を受けた本番のrelease-control.jsonでstopAIをtrueにして公開します。既に開始した送信を取り消したり、オフライン端末を遠隔停止することはできません。利用者へ無効化・キー失効を案内します。
  3. 全体停止が必要ならstopAppをtrueにして公開し、採点・返却を中止する告知を出します。保存データを削除しないでください。既存タブ・旧キャッシュ版・オフライン端末には停止が届かない場合があります。
  4. 実URL・通常タブ・新規タブで停止状態を確認し、管理者と利用者へ通知します。旧公開先にも影響がある場合は、旧版の利用中止も個別に案内します。
  5. 修正候補で通信・採点・保存・復元の回帰テストを再実行し、バックアップ復元を確認します。承認後に修正版と停止解除を公開し、実URLを再確認します。

stopAppによる全面停止時も、その端末で開いていたテストのバックアップ保存は利用できます。他のテストへの切替は復旧後に行ってください。ブラウザーの保存データは消さず、停止前のバックアップを保管してください。外部APIの失効操作、全停止の実運用訓練、利用者への連絡網は未確認です。
