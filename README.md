# キリマル Web版

提供：zoemonlab。現在の公開先： https://zoemon-lab.github.io/kirimaru/

このリポジトリはWeb版のみです。ネイティブのMacアプリとは別に保守します。AI採点はありません。AIは、教員が氏名などを隠して確認した先頭1人分の画像PDFから、解答欄・番号・配点を設定するために使います。APIキーをブラウザーに保存します。自動送信はしません。実APIの利用可否・契約は利用者側で確認してください。

## 更新時の注意

- Web版を、Macアプリのソースや共有の旧PWA生成処理で上書きしないでください。ネイティブ版の機能変更や再ビルドをWeb更新に含めないでください。
- `index.html` のモジュール本文を変更した場合は、CSPの最初の `sha256-...` をその本文のSHA-256（Base64）に更新してください。2番目は印刷用の固定スクリプトです。
- アセット更新時は `sw.js` の `CACHE` を新しい版名へ変更し、実際のService Workerで更新とオフライン動作を確認してください。
- 実在の答案・名簿・成績・APIキーをコミットしないでください。バックアップや通信ログも公開リポジトリへ追加しないでください。
- 外部依存物は `vendor/` に固定版を同梱しています。実行時のCDN取得は行いません。

## 停止・復旧

`docs/emergency-stop.html` を参照してください。停止設定はネットワーク優先で取得しキャッシュしません。オフライン端末や既存の旧版タブへの即時停止は保証できません。ブラウザーのサイトデータは削除しないでください。

## 利用・二次配布

キリマル本体の無断での二次配布・転載・再公開を禁止します。紹介・共有には https://zoemon-lab.github.io/kirimaru/ を使用してください。利用者の作成・出力データにはこの制限を適用しません。同梱OSSにはそれぞれのライセンスが適用されます。

### 2026-11-11 更新内容（一般公開の告知前）

- PDFは取り込み前にプレビューし、元のページのまま／連続2ページを左右に連結を選べます。白紙・模範解答もドラッグ＆ドロップ対応です。左右連結する場合、各PDFのページ数は偶数が必要です。
- 解答欄設定の「表示する用紙」で白紙・模範解答・答案を選択できます。答案と縦横比が違う補助用紙は警告し、枠の編集を止めます。同じページ構成で取り込んでください。
- 上部の次の作業ボタンで準備→採点→確認へ進めます。検出の詳細は折りたたみ、端末内での枠提案を主操作にしています。
- 解答欄設定で満点との配点照合、採点画面で取り消し・やり直し（直近100操作、一括採点は1操作）、小問の先生用メモ・部分点ボタンを利用できます。
- 答案の💬からコメント・「あとで確認」を保存できます。確認フラグが残る生徒は確認済みにできません。コメントは返却PDFや模範解答に自動で印刷されず、先生用CSVに任意出力できます。集計表の個票用コメントとは別です。
- バックアップの前回書き出し時刻・端末内の容量目安を表示し、復元前に内容を確認します。ダウンロード先への保存完了はブラウザから確認できません。復元は別テストとして追加し、取り消し履歴は安全のため空にします（得点・メモ・コメント・部分点設定は復元）。
- AI採点、答案画像の採点情報による並び替え・絞り込み、集約コメントの模範解答画像への付加は追加していません。AI解答欄設定の送信前確認・黒塗り・緊急停止は維持しています。

### 公開前監査による修正（2026-11-11）

- 保存失敗時も画面の最新状態をバックアップに書き出せます。削除と旧データ引き継ぎは画像・テスト情報をまとめて確定し、中断時は元データを保持します。
- 同時編集タブをロックし、採点後のページ数変更、得点を下回る配点変更、採点済み枠の種類変更を防ぎます。
- 復元時に重複ID・予約語ID・画像の破損や寸法・名簿と画像の順序・採点参照・個票の色などを検証します。バックアップは信頼できるものだけを使用してください。
- APIキーは初期状態ではタブ内のみ保存し、専用端末への継続保存は明示的な選択が必要です。両方式ともアプリ独自の暗号化はなく、同一オリジンの別アプリから完全には分離できません。
- 未解決の確認フラグは最終出力を止め、未採点・配点チェック・最終確認前の状態は下書き出力の確認を出します。CSVの数式文字列を無害化しています。
- 互換性用の公式PDF.jsビルドを使用し、画像はIndexedDBにバイト列として保存します（従来のBlob保存形式も読み込めます）。
- 表示中のオンライン端末は約60秒ごと・画面復帰時に緊急停止設定を確認します。送信直前の停止確認も維持。送信済みデータの取り消しや、オフライン端末の遠隔停止はできません。
- この監査・動作検証は、特許の非侵害保証や、学校での利用許可、実契約のAIサービスの適合性確認を意味しません。
