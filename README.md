# キリマル Web版

提供：zoemonlab。現在の公開先： https://keishukuwazoesoccer-cpu.github.io/kirimaru/

このリポジトリはWeb版のみです。ネイティブのMacアプリとは別に保守します。AI採点はありません。AIは、教員が氏名などを隠して確認した先頭1人分の画像PDFから、解答欄・番号・配点を設定するために使います。APIキーをブラウザーに保存します。自動送信はしません。実APIの利用可否・契約は利用者側で確認してください。

## 更新時の注意

- Web版を、Macアプリのソースや共有の旧PWA生成処理で上書きしないでください。ネイティブ版の機能変更や再ビルドをWeb更新に含めないでください。
- `index.html` のモジュール本文を変更した場合は、CSPの最初の `sha256-...` をその本文のSHA-256（Base64）に更新してください。2番目は印刷用の固定スクリプトです。
- アセット更新時は `sw.js` の `CACHE` を新しい版名へ変更し、実際のService Workerで更新とオフライン動作を確認してください。
- 実在の答案・名簿・成績・APIキーをコミットしないでください。バックアップや通信ログも公開リポジトリへ追加しないでください。
- 外部依存物は `vendor/` に固定版を同梱しています。実行時のCDN取得は行いません。

## 停止・復旧

`docs/emergency-stop.html` を参照してください。停止設定はネットワーク優先で取得しキャッシュしません。オフライン端末や既存の旧版タブへの即時停止は保証できません。ブラウザーのサイトデータは削除しないでください。
